开始使用

    

      在右上角输入一个 Cercis 项目文件夹的路径，然后点「打开项目」。

      还没有项目？用内核命令行创建一个：cercis init ./我的项目 --name "我的项目"
    

    

      
或者：用项目向导新建一个项目

      

        项目向导是基础工具包里的一个插件（项目内插件需先信任；全局安装的插件直接可用）。
